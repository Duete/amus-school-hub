# St Maria Goretti admission reference

Source: https://www.stmariagorettikatende.sc.ug/admission.html

Observed structure on 2 November 2026:

- Green admission hero with the heading "Admission Application" and a short invitation.
- Four-step progress indicator: Student Info, Academics, Parent, Contact.
- First step fields: Full Name, UNEB Index Number, Date of Birth, Sex, Religion, Nationality, and Home District.
- A single Next button advances the form.
- Footer repeats school contact details and practical admissions/resource links.

The Amus implementation will use the same practical multi-step information architecture without copying St Maria Goretti’s branding, text, or assets. Existing Amus backend fields and enquiry submission behavior will remain intact.
